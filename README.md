# 🎙️ KalamAI
### *"Your Words, Our Voice"*

Multilingual offline TTS Android App powered by **Piper AI**
Supports: English • Hindi • Urdu • Hinglish • German • French • Spanish • Portuguese

## Features
- 🌍 8 Languages: EN, HI, UR, Hinglish, DE, FR, ES, PT
- 🌙 Dark/Light Mode Auto Switch
- ⚡ Speed Control 0.5x — 2.0x
- 💾 Save Audio as WAV
- 📵 100% Offline after voice model download
- 🆓 Free Forever — No ads

## Build APK
Go to **Actions** tab → **Build KalamAI APK** → **Run workflow**
Download APK from Artifacts after build completes (~25 min).

## Install on Phone
Settings → Security → Unknown Sources ON → Install APK
